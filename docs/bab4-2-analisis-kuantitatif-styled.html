4.6.4 Hasil Uji Instrumen

A. Uji Validitas (Pearson Item-Total)

r = [n*Sigma(XY) - (Sigma X)(Sigma Y)] / sqrt([n*Sigma(X^2) - (Sigma X)^2][n*Sigma(Y^2) - (Sigma Y)^2])

Kriteria: n = 17, df = 15, alpha = 0.05 (dua sisi), r_tabel = 0.48215. Item valid jika r_hitung > r_tabel.

B. Uji Reliabilitas (Cronbach's Alpha)

alpha = (k/(k-1)) * (1 - (Sigma Var(item) / Var(total))) alpha = (5/4) * (1 - 3.9926/13.0588) = 0.8678

Nilai alpha = 0.8678 > 0.70, sehingga instrumen dinyatakan reliabel.

4.6.5 Uji Asumsi Klasik

Model regresi menggunakan variabel bebas X = rata-rata(Q1, Q2, Q3R, Q4) dan variabel terikat Y = Q5.

  • Uji normalitas residual (Shapiro-Wilk): W = 0.9856, p = 0.9913 (normal).
  • Uji linieritas (deviasi dari linearitas): F_dev = 0.0000398, p = 0.9951 (linear).

4.6.6 Hasil Regresi dan Uji Hipotesis

A. Persamaan Regresi

Diperoleh koefisien b0 = 2.0328 dan b1 = 0.6234, sehingga:

Y = 2.0328 + 0.6234X

Interpretasi: setiap kenaikan 1 poin persepsi kualitas aplikasi meningkatkan skor keberlanjutan penggunaan sebesar 0.6234 poin.

B. Koefisien Korelasi dan Determinasi

  • r = 0.7341 (hubungan positif kuat)
  • R² = 0.5389 (53.89% variasi Y dijelaskan oleh X)

4.6.7 Kesimpulan Analisis Kuantitatif

Kesimpulan utama:

  1. Data 17 responden menunjukkan kecenderungan penilaian positif terhadap aplikasi.
  2. Instrumen valid dan reliabel (alpha = 0.8678).
  3. Asumsi regresi terpenuhi (residual normal dan hubungan linear).
  4. Uji t dan uji F menunjukkan pengaruh signifikan variabel kualitas persepsi aplikasi terhadap keberlanjutan penggunaan.
  5. Model akhir: Y = 2.0328 + 0.6234X dengan R² = 0.5389.
